# 06. 브랜드

로고, 마스코트, 색의 기준이다. 로고 원본은 `public/brand`(워드마크 `wordmark.svg`, 심볼 `symbol.svg`)이고, 앱 아이콘은 `public/icons`에 있다. 처음 로고와 마스코트는 [Figma TailQ › 06 브랜드](https://www.figma.com/design/wPjTOU5FJdhdrMWOGZTHdh)에 컴포넌트로 있다.

## 방향

**시크하고 절제된 느낌.** 귀엽거나 캐릭터풍인 표현은 쓰지 않는다. 브랜드의 줄기는 **여우 꼬리**다. "꼬리질문(Tail Question)"과 "꼬리잇기"를 한 이미지로 묶는다.

## 로고

2026-10-28에 새 워드마크와 Q 심볼로 바꿨다.

| 종류 | 모양 | 쓰는 곳 | 파일 |
|---|---|---|---|
| 워드마크 | "TailQ". **Tail**은 사선 컷이 들어간 테크니컬 글자, **Q**는 꼬리가 여우 꼬리로 휘어진 Q | 앱 머리 막대, 랜딩·공유·체험 결과 머리, 푸터, 공유 미리보기 이미지(오렌지 Q 표시 옆) | `public/brand/wordmark.svg` |
| 심볼 | 워드마크의 여우 꼬리 Q 하나 | 앱 아이콘, 파비콘, 알림 배지, 오렌지 Q 표시(로그인 위쪽·공유 미리보기), 작은 자리(기록 상세의 "AI 코멘트" 앞) | `public/brand/symbol.svg` |

- 심볼은 워드마크의 Q와 **같은 모양**이어야 한다. 파비콘을 봐도 워드마크가 떠오르게 하려는 것이다.
- 두 파일 모두 단색 path 하나다. 테마마다 파일을 따로 두지 않는다.
- **두 색 워드마크**: 화면의 워드마크는 몸통을 글자색(`--text`: 라이트 `#111312`, 다크 `#EDEEEC`), Q 꼬리를 `--brand-tail`(라이트 `#B83505`, 다크 `#FF7A45`)로 칠한다. 모든 화면이 같고, 운영 화면에서도 꼬리는 오렌지 그대로다(남색으로 바뀌는 건 `--accent`뿐). `components/Logo.tsx`가 path를 인라인 SVG로 그리고 꼬리 영역(`components/logo-paths.ts`)으로 몸통과 꼬리를 나눠 겹치지 않게 칠한다. 메신저 미리보기 이미지는 지금처럼 다크 글자색 단색으로 칠해 넣는다.
- **크기**: 머리 막대의 워드마크 높이는 모바일 30px, 태블릿·PC 34px(랜딩·공유 머리도 같다). 푸터는 22px. 주변 여백은 8px 이상. 처음엔 24px였는데 "로고가 작아 서비스 인상이 약하다"는 의견으로 사이드 메뉴 34px, 모바일 헤더 30px로 키웠고(#110), 리셋에서 사이드 메뉴가 상단 메뉴로 바뀐 뒤에도 같은 크기를 쓴다.
- 처음 워드마크는 "TailQ"의 마지막 Q 꼬리가 여우 꼬리로 휘어진 모양이었고(아래 "만든 과정" 2번), 라이트 `#111418`, 다크 `#ECEEF1` 파일을 테마마다 바꿔 썼다.
- **오렌지 Q 표시**(앱 아이콘과 같은 primary 바탕 + on-primary Q, 모서리 radius.panel, Q는 한 변의 62%)는 로그인 화면 위쪽(워드마크 대신, 모바일 48px·태블릿·PC 56px)과 공유 미리보기 이미지(64px, 워드마크 왼쪽)에만 쓴다.
- `public/brand/q-dark.png`, `q-light.png`는 3D 로고 작업에 쓰는 Q 이미지다. 화면에는 쓰지 않는다.

### 앱 아이콘

| 종류 | 모양 | 파일 |
|---|---|---|
| 일반 | 시그널 오렌지 `#FF4F12` 바탕에 `#111312` Q 심볼. Q 폭은 아이콘의 **62%** | `public/icons/icon-192.png`, `icon-512.png`, `public/apple-touch-icon.png` |
| maskable | 같은 색. 원형 마스크의 안전 영역에 들어가게 Q 폭 **52%** | `public/icons/icon-maskable-512.png` |
| 파비콘 | 같은 색. 작은 크기에서도 보이게 Q 폭 **74%** | `app/favicon.ico` |
| 알림 배지 | 흰 Q 실루엣, 투명 바탕 | `public/icons/badge-96.png` |

- 오렌지 위 Q는 흰색이 아니라 어두운 `#111312`다. 오렌지 위 흰 글자는 대비가 3.29:1이라 화면의 주 버튼과 같은 규칙을 따른다.
- 설치한 앱의 실행 화면 바탕·상단 색은 앱 기본 다크 바탕 `#0E0F0E`이다(`app/manifest.ts`).
- 로고 파일이 바뀌면 `public/brand`와 파비콘·앱 아이콘을 함께 다시 만든다.
- 처음 앱 아이콘은 `#111418` 바탕에 밝은 심볼이 기본이고 틸(`#0E7C66`) 바탕이 보조였다.

## 마스코트

꼬리를 발 앞으로 감싸고 앉은 **여우 실루엣**이다. 꼬리 끝의 흰 부분이 로고의 Q 꼬리와 같은 모양이다.

- 얼굴 표정(눈, 입)은 넣지 않는다.
- **2026-10-28 디자인 리셋부터 화면에 쓰지 않는다.** 마스코트 없이도 서는 화면을 기준으로 삼았다. 처음엔 랜딩(꼬리잇기 섹션에 크게), 로그인 화면, 빈 화면·한도 소진, PC 앱의 피드백 버튼에 썼다. 기본 아바타도 여우가 아니라 무채색 원 안의 닉네임 첫 글자다.
- 여우 꼬리는 리포트의 꼬리잇기 제목 앞 작은 무채색 아이콘으로만 남아 있다.
- 다시 쓴다면 색은 필터로 뒤집지 않고 벡터 fill을 테마 토큰으로 바꾼다.

## 색

**무채색 바탕에 시그널 오렌지 하나**를 강조색으로 쓴다(2026-10-28 디자인 리셋). 오렌지는 여우 꼬리에서 온 브랜드 색이고, 지금 할 일·오늘·이어 가기에만 쓴다. 강조색을 채운 버튼은 화면마다 하나다.

| 역할 | 라이트 | 다크 |
|---|---|---|
| 배경 | `#F3F4F2` | `#0E0F0E` |
| 본문 글자 | `#111312` | `#EDEEEC` |
| 보조 글자 | `#5B605D` | `#A4A9A5` |
| 안내 글자 | `#6A6F6B` | `#8A8F8B` |
| 강조 (글자·선) | `#B83505` | `#FF7A45` |
| 강조 (버튼 채우기) | `#FF4F12` + 글자 `#111312` | `#FF5A1F` + 글자 `#0E0F0E` |
| 틀림·낮은 점수·오류 | `#B0123B` | `#FF6B86` |

- 밝은 오렌지(버튼 채우기)를 글자로 쓰지 않는다. 대비가 모자라서 강조 글자는 진한 오렌지다.
- 틀림·실패는 오렌지가 아니라 진홍으로, 모양(네모 점)과 함께 표시한다.
- 면·선·빈 칸 같은 나머지 토큰은 [07 UI 디자인](07-ui-design.md)에 있다. 코드의 기준값은 `lib/theme.ts`다.
- **처음 색 (2026-10-21~24)**: 중립 회색에 딥 틸 하나(배경 `#FFFFFF` / `#0E1013`, 강조 `#0E7C66` / `#34C79A`).
- **C안 색 (2026-10-25~27)**: 녹색 기운의 배경(`#EAF1EE` / `#07100E`)에 민트 강조(글자·선 `#0E7C66` / `#7CF2CD`, 버튼 채우기 `#34C79A`). 유리 질감을 보이려고 배경에 빛을 깔았다. 리셋에서 유리와 함께 걷어내고 지금 색으로 바꿨다.

## 만든 과정

1. 로고 1차: "꼬리가 긴 Q" 4종 → 모두 탈락
2. 로고 2차: 워드마크, TQ 모노그램, 말풍선, 여우 꼬리 Q → 워드마크에 여우 꼬리 Q를 합치기로 결정
3. 마스코트: 검은 고양이(GitHub 옥토캣과 겹칠 우려)와 추상 캐릭터를 거쳐 여우 실루엣으로 결정
4. 고른 안을 벡터로 정리해 Figma 컴포넌트로 만듦
5. 색을 C안(녹색 기운 배경, 민트 강조 두 가지)으로 바꿈 (2026-10-25)
6. 디자인 리셋: 워드마크를 새로 만들고(Tail 테크니컬 글자 + 여우 꼬리 Q), 앱 아이콘을 시그널 오렌지 바탕으로, 색을 무채색 + 시그널 오렌지로 바꿈. 마스코트는 화면에서 뺌 (2026-10-28)
