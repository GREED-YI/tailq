# 06. 브랜드

로고, 마스코트, 색의 기준이다. 원본은 [Figma TailQ › 06 브랜드](https://www.figma.com/design/wPjTOU5FJdhdrMWOGZTHdh)에 컴포넌트로 있다.

## 방향

**시크하고 절제된 느낌.** 귀엽거나 캐릭터풍인 표현은 쓰지 않는다. 브랜드의 줄기는 **여우 꼬리**다. "꼬리질문(Tail Question)"과 "꼬리잇기"를 한 이미지로 묶는다.

## 로고

| 종류 | 모양 | 쓰는 곳 |
|---|---|---|
| 워드마크 | "TailQ". 마지막 Q의 꼬리가 여우 꼬리로 휘어진다 | 랜딩, 상단바, 공유 카드 |
| 심볼 | 워드마크와 같은 여우 꼬리 Q 하나 | 앱 아이콘, 파비콘, 작은 자리 |

- 심볼은 워드마크의 Q와 **같은 모양**이어야 한다. 파비콘을 봐도 워드마크가 떠오르게 하려는 것이다.
- 라이트 배경에는 `#111418`, 다크 배경에는 `#ECEEF1`로 쓴다. 테마가 바뀌면 워드마크도 라이트용·다크용으로 바꾼다.
- 앱 아이콘은 `#111418` 바탕에 밝은 심볼이 기본이고, 틸(`#0E7C66`) 바탕은 보조로 쓴다.

## 마스코트

꼬리를 발 앞으로 감싸고 앉은 **여우 실루엣**이다. 꼬리 끝의 흰 부분이 로고의 Q 꼬리와 같은 모양이다.

- 얼굴 표정(눈, 입)은 넣지 않는다.
- 쓰는 곳: 랜딩(꼬리잇기 섹션에 크게), 로그인 화면, 빈 화면·한도 소진, 프로필 기본 아바타(원 안에 넣어 56·96px)
- 색은 필터로 뒤집지 않고 벡터 fill을 테마 토큰으로 바꾼다.
- **역할 구분**: 3D Q는 채점하고 되묻는 **AI 면접관**(기능), 여우는 꼬리잇기·응원 같은 **정서적인 장면**. 둘을 섞어 쓰지 않는다.

## 색

**녹색 기운의 배경에 민트 강조색**을 쓴다(C안, 2026-10-25). 배경에 민트·청록 빛 덩어리를 깔고 그 위에 유리 면을 올린다. 강조색을 채운 버튼은 화면마다 하나다.

| 역할 | 라이트 | 다크 |
|---|---|---|
| 배경 | `#EAF1EE` | `#07100E` |
| 본문 글자 | `#0F1A17` | `#ECF3F0` |
| 보조 글자 | `#4B5A55` | `#A3B5AE` |
| 안내 글자 | `#66756F` | `#7E948C` |
| 강조 (글자·선) | `#0E7C66` | `#7CF2CD` |
| 강조 (버튼 채우기) | `#34C79A` + 글자 `#04140F` | `#34C79A` + 글자 `#04140F` |
| 보완 필요 | `#B45309` | `#F0A44B` |

- 민트(`#34C79A`)를 흰 바탕 위 글자로 쓰지 않는다. 대비가 모자라서 라이트의 강조 글자는 `#0E7C66`이다.
- 유리 면, 바텀 시트, 배경 빛 같은 나머지 토큰은 [07 UI 디자인](07-ui-design.md)에 있다.
- **처음 색 (2026-10-21~24)**: 중립 회색에 딥 틸 하나(배경 `#FFFFFF` / `#0E1013`, 면 `#F6F7F8` / `#171A1F`, 선 `#E6E8EB` / `#2A2F37`, 강조 `#0E7C66` / `#34C79A`). 유리 질감을 쓰는 C안으로 가면서 배경에 녹색 기운과 빛을 넣었고, 다크에서는 버튼 채우기와 글자 강조를 나눴다. 라이트 강조 `#0E7C66`과 보완색은 그대로 두었다.

## 만든 과정

1. 로고 1차: "꼬리가 긴 Q" 4종 → 모두 탈락
2. 로고 2차: 워드마크, TQ 모노그램, 말풍선, 여우 꼬리 Q → 워드마크에 여우 꼬리 Q를 합치기로 결정
3. 마스코트: 검은 고양이(GitHub 옥토캣과 겹칠 우려)와 추상 캐릭터를 거쳐 여우 실루엣으로 결정
4. 고른 안을 벡터로 정리해 Figma 컴포넌트로 만듦
5. 색을 C안(녹색 기운 배경, 민트 강조 두 가지)으로 바꿈 (2026-10-25)
